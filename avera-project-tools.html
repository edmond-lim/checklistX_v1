Compares a source folder against the target (project) folder, tells you which files are newer where, flags anything edited directly in the target, and lets you push updates with one click.

This tool needs Chrome or Edge. It uses the File System Access API to read and write local folders directly, which Firefox and Safari don't support. Please reopen this file in Chrome or Edge.

Folder Set Generator

This tool needs the File System Access API, available in Chrome or Edge on desktop. You can still plan the naming and subfolder list below, but folder creation is disabled in this browser.
