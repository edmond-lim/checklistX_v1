Trade Entry Desk, start to finish

How a trade actually gets from the form into your permanent log and your spreadsheet, in order.

How saving works

Read this once. It decides whether a trade you save is safe or stuck in one browser.

Two different things happen when you click "Save trade & log it," depending on where you opened the form.

Opened from the Claude artifact link

The whole page republishes with your trade baked into the History table. It is now permanent, on that link, visible from any device you open it from.

Opened as a downloaded HTML file

There is no link to republish to, so the trade is written to that browser's local storage only. The toast will say it does not sync to other PCs. Close that browser's data and it is gone.

Either way, the on-page History table and its downloads (Markdown/HTML cards) are a backup, but the spreadsheet is still your real source of truth. Get every trade into it via the copy buttons below, don't rely on the form as your permanent ledger.

Log a trade

Do this every time you close or fully plan a trade.

  1. Open the form

    Use the Claude artifact link if you want the trade permanently logged there, or the downloaded HTML file for quick offline entry.

  2. Fill in Trade basics

    Date, account number, then Strategy first, since it drives which Setup, Value Location, and strategy-specific fields appear below it.

  3. Work through Setup and Entry type, then the strategy-specific fields

    Each strategy shows its own checklist and fields (X-COT, session block, position tier, and so on, depending on which one you picked).

  4. Check GRADE (AUTO)

    It updates live as you fill fields in and mirrors the spreadsheet's own grading formula, so what you see here is what will land in the sheet.

  5. Add mindset, outcome fields, and screenshots

    Photos attach to the downloadable trade card only; they are not kept in the page's saved log, so download the card if you want to keep them.

  6. Click Save trade & log it

    First save from a fresh browser may prompt for download permission. Allow it, or downloads will silently fail later.

Get it into your spreadsheet

The form never edits your workbook directly, it only prepares rows for you to paste.

  1. Set the target row

    The row number field defaults to the next open row, change it only if you're backfilling an older trade.

  2. Click Copy spreadsheet row for one trade, or Copy all as spreadsheet rows for everything logged this session

    This copies tab-separated values to your clipboard, formatted to match the Trade Log tab's columns.

  3. Click the first cell of that row (column A) in Trade Log

    Then paste. The ID, Day, Asset Class, streaks, Grade (Auto), Cum RR, Trade ID, and helper columns stay as live formulas for that row; everything else pastes as your entered values.

  4. Download the trade card

    Download Markdown card and Download HTML card save a readable copy with your screenshots embedded, named date_account_strategycode_instrument so nothing collides as you log more trades.

Mirror the workbook to Google Sheets

One-time setup, then the same copy-paste habit works there too.

  1. Upload the workbook

    Drag X_Concepts_Backtesting_Journal_MultiStrategy.xlsx into Google Drive.

  2. Convert it in place

    Right-click the file, choose Open with, then Google Sheets. Drive converts it natively, so every tab, column, and formula carries over exactly, with no risk of the file getting corrupted along the way.

  3. Use it exactly like Excel from here on

    The same Copy spreadsheet row / Copy all buttons paste cleanly into this Sheet, since its Trade Log tab has the identical layout and formulas the copy format was built for.

  4. Keep one file as the source of truth

    The xlsx and the Sheet are now two separate files, editing one does not update the other. Pick one to actually log into going forward, and keep the other as a backup or drop it entirely.
